# AGENTS.md — Repo rules (humans and AI coding tools)

## Hard rules
1. **Never call a cloud AI API.** No OpenAI, Anthropic, Gemini, HF Inference, AI Gateway, or any server-side model. All inference runs in the browser (WebLLM, transformers.js).
2. No backend. No API routes that do AI or store user data. User data lives only in IndexedDB on the device.
3. No login, no analytics that send user requests or preferences anywhere.
4. The app must work offline after first load + model download. Test in airplane mode before merging UI changes.
5. Always keep the non-LLM path working (rule parser + template reason). Never make the LLM a hard dependency.

## Stack
Next.js (App Router) · TypeScript (strict) · Tailwind · shadcn/ui · `@mlc-ai/web-llm` · `@huggingface/transformers` · `idb-keyval` · Vercel (static export where possible). Scraper: Python 3.12, `requests` + `beautifulsoup4` (Playwright only if a site needs JS).

## Folder structure
```
src/
  app/                 page.tsx (home), setup/, results/, settings/, layout.tsx, manifest.ts
  components/          UI components; components/ui = shadcn (don't hand-edit)
  lib/
    ai/                llm.worker.ts, llm.ts (load/progress/generate), embed.ts, prompts.ts
    parse/             rules.ts (fallback parser), validate.ts (JSON contract → Filters)
    rank/              combos.ts, score.ts, distance.ts
    store/             db.ts (idb-keyval wrappers), prefs.ts, taste.ts
    types.ts           CatalogItem, Branch, Prefs, TasteProfile, Filters, Combo, Result
public/
  catalog.json         generated by scraper (mock until data is ready)
  sw.js, icons/
scraper/               Python scraper + manual_fixes.csv → writes ../public/catalog.json
tests/
  prompts.md           15 Taglish cases (source of truth for the parser)
  parse.test.ts        runs prompts.md cases against rules.ts (and LLM when available)
```

## Conventions
- Types in `lib/types.ts` must match SPEC.md §3–4 exactly. Change the spec first, then the type.
- Pure functions in `lib/rank` and `lib/parse` — no React, no I/O — so they're testable with `vitest`.
- Heavy AI work runs in a Web Worker. Never block the main thread.
- Chain ids: `jollibee`, `mcdonalds`, `mang-inasal`, `chowking`. Item ids: `<chain-prefix>-<slug>`.
- Prices are integers in pesos. Distances in km. Times in minutes.
- UI copy: short Taglish, friendly. Peso sign `₱`.
- Mobile first: design at 375 px wide, tap targets ≥ 44 px.
- Commits: small, `feat:`, `fix:`, `docs:`, `data:` prefixes. Work on branches, PR into `main`.
- Don't add dependencies without telling the team in chat (bundle size matters on phones).
